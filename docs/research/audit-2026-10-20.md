## Claude Code 2.1.304

- The system-prompt date line is `Today's date is ${iMo(e)}.` with an ASCII apostrophe. `sMo` always formats
  `YYYY-MM-DD` with `-`. No `Asia/Shanghai` or `Urumqi` literal exists in the binary. The endpoint/timezone-dependent
  apostrophe and separator logic described in issue #67120 (v2.1.169) is **not present in this code path**.
- `sMo` prefers a host-supplied session time zone when one is set, and falls back to `UTC` in some modes.
  Otherwise it uses the process's local date, so `TZ` decides which calendar day appears.
- Locale reaches telemetry in one observed place: `tengu_voice_recording_started.systemLocaleLanguage` (the `Intl`
  locale language), sent when voice input is used.
- Prompt text that includes the zone appears only in features that use it: the cloud-schedule skill (`userTimezone`,
  `nowLocal`) and the MCP date-parse helper (`Local timezone`).
- Documented opt-outs present in the binary: `DISABLE_TELEMETRY`, `DISABLE_ERROR_REPORTING`.

Consequence: a process-scoped `TZ`/`LANG`/`LC_ALL` wrapper controls what Claude Code derives from the local clock
and locale for that process. It does not change the network address, the account, or server-side signals.

## Claude Desktop 2.42304.0

See [desktop-chat-feasibility.md](desktop-chat-feasibility.md). In short: Desktop sets `TZ` for its Code-tab
children from its own `Intl` zone. Debug switches make it exit at startup. It passes
`preferredSystemLanguages` to the Chat renderer natively. On this Mac, no isolated test instance can be
started safely.

## claude.ai in a browser

The page's JavaScript reads the time zone and language from `Intl`, `Date` and `navigator.language(s)`, and the
browser sends `Accept-Language`. A MAIN-world document_start override plus a declarativeNetRequest header rule
covers those for claude.ai frames that Chrome injects into. Not covered: Web Workers, the network address, the
account country, and detection of the override itself. We have not yet observed which of these values claude.ai
sends in its own request bodies (doing so would need a signed-in session).

  `scripts/build-mac.sh` are not written yet.
- `extension/core/override.js`: the MAIN-world override, untested. Manifest, background, UI and Playwright tests
  are not written yet.
