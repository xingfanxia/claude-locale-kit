# Audit, 2026-10-20: where time zone and locale reach Claude

Scope: which of Claude Code CLI, Claude Desktop and claude.ai on macOS a user-chosen time zone and locale can
change. Method: static inspection of shipped binaries and pinned third-party sources; no runtime capture yet.
**Current-version caveat:** findings are pinned to the versions below and must be re-checked on upgrade.
Observed = seen in code or files; Inferred = reasoned, not tested; Unknown = not determined.

## Credibility of the prior research

- **The three repositories are real and readable at the pins above.** Each one describes an approach. None of them
  shows validation against current Claude clients. cc-gateway labels itself Alpha. Its claims are design
  statements, not test results.
- **The claude-telemetry-audit sanitizer corrupts JSON. Observed:** `scripts/mitmproxy_privacy_sanitizer.py` replaces
  the raw bytes of U+201C/U+201D with an unescaped `"` across the whole request body. Reproduced locally: a body whose
  message text contains `“hi”` becomes `{"content": "He said "hi""}`, which fails `json.loads`. It also rewrites the
  user's own text, and its map omits U+02B9, one of the four apostrophe variants that issue #67120 lists.
- **Its README's "100%" (blocking) and "80%" (time zone leakage) figures** are not backed by any measurement in the
  repository.
- **The old date-line logic.** Issue #67120 describes endpoint- and timezone-dependent apostrophe and separator
  variants in v2.1.169. In 2.1.304 the static code path builds a plain line (below). That shows absence in the
  inspected path of this version only. It is not a runtime test, and it says nothing about other channels.
- **The "experiment rolled back" statement.** A post attributed to an Anthropic employee, dated 2026-06-30, appears in
  a search index. A direct fetch returned HTTP 403, so the primary text was not read here. It is not a test of the
  current version either.

## Claude Code 2.1.304 (observed, static)

- The system-prompt date line is `Today's date is ${iMo(e)}.` with an ASCII apostrophe. `sMo` formats `YYYY-MM-DD`
  with `-`. The binary contains no `Asia/Shanghai` or `Urumqi` literal.
- `sMo` uses a host-supplied session time zone when one is set, falls back to `UTC` in some modes, and otherwise uses
  the process's local date. Inferred: `TZ` decides which calendar day appears for a CLI process.
- `tengu_voice_recording_started.systemLocaleLanguage` carries the `Intl` locale language when voice input is used.
- The cloud-schedule skill (`userTimezone`, `nowLocal`) and the MCP date-parse helper (`Local timezone`) put the zone
  into prompt text when those features run.
- The binary contains the documented opt-outs `DISABLE_TELEMETRY` and `DISABLE_ERROR_REPORTING`.
- Not determined: every other channel. This is a string-level inspection, not a full data-flow trace.

## claude.ai in a browser (design intent, untested)

The page's JavaScript can read the zone and language from `Intl`, `Date` and `navigator.language(s)`, and the browser
sends `Accept-Language`. The planned extension overrides those in the claude.ai frames that Chrome injects into,
and sets the header with a declarativeNetRequest rule. Known not to be reached: Web Workers, the network
address, and the account. Unknown: which of these values claude.ai puts into its own request bodies.
